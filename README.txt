CLIXY AUTO SHIPPING - WEBHOOK FIX

1) Vercel Environment Variable:
   EASYORDERS_API_KEY = your existing EasyOrders Public API key
   EASYORDERS_WEBHOOK_SECRET = optional. Only add it if you want to validate
   the secret generated by EasyOrders. If you add it, it must exactly match
   the `secret` header sent by EasyOrders.

2) EasyOrders Webhook:
   URL: https://clixy-theta.vercel.app/api/easyorders
   Type: Orders
   Enabled: ON

3) IMPORTANT:
   The Order Created webhook contains the complete order and, in your actual
   test payload, short_id=22. This version uses that payload directly and
   does NOT first call GET /orders/{uuid}, avoiding the previous permission
   denied problem.

4) Automatic flow:
   EasyOrders POST -> /api/easyorders -> read short_id -> call
   /api/label?order=SHORT_ID -> label URL is ready.

5) Manual test:
   https://clixy-theta.vercel.app/api/label?order=22

6) Webhook test:
   Create a new order and inspect Vercel Logs. A successful webhook should
   return HTTP 201 and JSON containing:
   label_generated: true
   label_url: https://clixy-theta.vercel.app/api/label?order=NUMBER

Security:
   Do not publish the EasyOrders webhook secret or API key in screenshots.
